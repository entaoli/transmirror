Translation Engines

双引擎翻译架构

引擎一负责“术语准确”，引擎二负责“地道表达”。

引擎一：术语防漂移三道防线

AI 介入前执行

三道防线依次拦截，确保 18,000+ 条专有术语在任何语言下都不漂移。

预译和批量翻译共用此服务。

L1

强制替换 local_replace()

文档中所有被 【UI元素】 或 **加粗** 标记的词条，在 AI 介入前直接硬替换为目标语言。1:1 锁死，绝无歧义，确保按钮名称、菜单路径与产品界面完全一致。

强制替换示例
zh→en
勾选 **加速导出** 选项，点击 【保存】 按钮
→
勾选 **Accelerate Export** 选项，点击 **Save** 按钮。
L2

术语扫描注入 scan_terms()

AI 翻译前，自动识别文档中的产品术语，按需生成上下文约束。动词、形容词、虚词、泛词等进行智能过滤，由 AI 自由发挥，保证句子流畅自然。

自定义页面 → Custom Page 外部门户 → External Portal 工作流 → Workflow 点击 → Click（排除） 保存 → Save（排除）
L3

可视透明

审校界面实时展示本次翻译「使用的词条」与「排除的词条」两组标签。译员一眼看穿 AI 的术语决策，随时可在 HAP 工作流或本地审校中介入修正。

引擎二：意图对齐引擎

双轮 AI 流水线

术语锁定后交由双轮 AI 处理：第一轮保语义，第二轮提风格。

仅用于批量翻译，日常中文修改的片段内容直接使用 GPT-5 翻译。

Round 1 · 直译层
gpt-5-mini
忠实翻译原文，严格执行注入的术语表，保留全部 Markdown 结构。只负责语义准确，不做风格优化。
Round 2 · 风格层
gpt-5
句式润色、去冗余、本地化语气适配。让文档读起来像母语者手写，而非机器直译。

post-commit hook 自动触发预译

图一：解析 diff，按锚点提取变更章节，推送到 HAP 工作表，状态设为「待翻译」。

图二：❶ 待翻译内容。❷ 自动替换【】和**加粗**的词条内容。❸ 扫描出正文出现的词条、自动注入到 AI 翻译提示词。

HAP 自动生成建议译文

工作流监测到新记录后，通过 AI 完成翻译，写回 建议译文 字段，全程无需人工干预。

译员打开审校页面

浏览器访问 localhost:8502，选择 HAP 工作表模式，筛选「待翻译」，加载变更列表。

审校译文

查看本次中文变更内容与命中的术语词条，对照 AI 建议译文进行确认和调整。译境自动提供上下文与术语决策依据，帮助译员快速完成审校。

复制并定位 · 编辑 · 保存 · 标记完成

点击复制按钮自动定位到锚点位置。 在右侧编辑器粘贴并修改译文，点击「保存」写入本地英文文件，点击「已完成」将状态同步回 HAP 工作表。

提交英文文件

将修改后的英文文件提交并推送到远程仓库，完成本次翻译闭环。

Installation

安装使用指南

译境运行在译员本地电脑，管理员分发安装包，译员一键完成安装。

前置要求

操作系统macOS（Apple Silicon / Intel 均支持）
Python3.10 及以上
Git已安装并配置好本地仓库
API KeyOpenAI API Key（向管理员获取）

安装步骤

1

获取 TransMirror 安装包

向管理员获取 TransMirror 目录压缩包，解压到本地任意位置，例如 ~/TransMirror。

2

运行一键安装脚本

打开终端，进入 TransMirror 目录，执行安装脚本。脚本将自动安装 Python 依赖、创建配置文件、注册开机自启动服务。

bash install.sh
3

编辑 .env 配置文件

安装完成后，编辑 TransMirror/.env，填写本地仓库路径和 API Key。

HELP_ROOT/Users/yourname/MDHelpCenter
DOCS_ROOT/Users/yourname/Private/Document  （可选）
OPENAI_API_KEYsk-xxx
4

重启服务

修改 .env 后需重启服务使配置生效。

launchctl unload ~/Library/LaunchAgents/com.transmirror.server.plist launchctl load ~/Library/LaunchAgents/com.transmirror.server.plist
5

快速访问

服务启动后，浏览器直接点击进入对应界面。

localhost:8502  ·  审校界面 localhost:8502/batch  ·  批量翻译
